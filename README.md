# Effective C++ Study

스콧 마이어스의 **Effective C++ (3판)**을 읽으며 항목별로 직접 예제를 만들어 보는 저장소입니다.
책은 C++98/03 기준이라, 각 항목을 **책의 방식**과 **모던 C++(C++20) 방식**으로 함께 실습합니다.

## 구조

```
ch02_ctor_dtor_assign/       2장. 생성자, 소멸자, 대입 연산자 (항목 5~12)
ch03_resource_management/    3장. 자원 관리 (항목 13~17)
  itemNN_<주제>/main.cpp     항목 하나 = 실행 파일 하나
```

각 `main.cpp` 맨 위에 책의 방식, 모던 C++ 방식, 실험 아이디어가 주석으로 정리되어 있습니다.

## 빌드 및 실행

**Visual Studio**: `파일 > 열기 > 폴더`로 이 폴더를 열면 CMake 프로젝트로 인식됩니다.
상단의 시작 항목 드롭다운에서 실행할 항목(예: `item05_compiler_generated_functions.exe`)을 고르고 실행하면 됩니다.

**명령줄**:

```bash
cmake -S . -B build
cmake --build build --target item05_compiler_generated_functions
```

빌드 설정: C++20, 경고 수준 `/W4`, `/permissive-`, `/utf-8`

## 새 항목 추가

1. 장 폴더 안에 `itemNN_<주제>/main.cpp`를 만든다.
2. 그 장의 `CMakeLists.txt`에 `add_item(itemNN_<주제>)` 한 줄을 추가한다.
3. 새 장이면 루트 `CMakeLists.txt`에 `add_subdirectory(<장 폴더>)`를 추가한다.
